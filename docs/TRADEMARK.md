## 4. 出願方法

### 方法A: 自分で出願 (J-PlatPat電子出願)
- **費用**: 印紙代のみ ¥18,000(3区分の場合)
- **手続**: J-PlatPat → 電子出願ソフトのダウンロード+設定 → 願書作成 → 提出
- **メリット**: 安い
- **デメリット**: 区分指定・指定商品の記載で判定誤りがあると拒絶理由通知が来る

### 方法B: 弁理士に依頼 (推奨)
- **費用**: 印紙代 + 弁理士費用 ¥30,000-100,000/件
- **手続**: 弁理士に相談 → 願書作成 → 提出 → 拒絶対応も依頼
- **メリット**: 拒絶リスク低、区分選定の最適化
- **おすすめ**: ココナラ・弁理士ドットコムで検索、初回相談無料

### 方法C: ToreRu / Cotobox (オンライン商標サービス)
- **費用**: ¥39,800〜/件 (1区分あたり)
- **メリット**: AI簡易調査、定額、進捗ダッシュボード
- **デメリット**: 弁理士相当のリスク管理は限定的

→ **方法B(弁理士)を推奨**。商業展開する以上、後で「侵害」と言われるリスクを最小化すべき。

## 5. 出願から登録までの流れ

```
1. 出願 (出願日が権利の優先日となる)
        ↓
2. 方式審査 (1-2ヶ月) - 書類の不備チェック
        ↓
3. 実体審査 (4-6ヶ月) - 既存商標との類似、識別力の有無
        ↓
4a. 拒絶理由通知 → 意見書/補正書で対応
4b. 登録査定 → 登録料納付 (¥32,900/3区分10年)
        ↓
5. 商標登録 → 公報掲載
        ↓
6. 10年ごとに更新 (¥38,800/3区分10年)
```

## 6. 出願後の運用

- **R マーク** (Registered) を商標と併記して使用 (「アニノベル®」)
- **TM マーク** は出願中・未登録でも使用可 (「アニノベル™」)
- 第三者の侵害発見時:
  1. 警告状送付 (内容証明)
  2. 削除要求 / 損害賠償請求
  3. 訴訟 (地裁)
- 自社ドメイン `aninovel.com` は商標と共に取得・保持必須
