# 作者収益還元プログラム 設計書

> 状態: 設計フェーズ。実装は #2+#3 (Supabase) + #10 (Stripe Connect) 完了後

---

## 1. 目的

「優れた作品を投稿すれば作者にも還元される」エコシステムを作り、**良質なコンテンツの集積**を促進する。
クリエイター流出 (note・カクヨム・なろうへの) を防ぎ、独自性を確立。

---

## 2. 還元方式の選択

### 比較

| 方式 | メリット | デメリット | 採用 |
|---|---|---|---|
| A. PV連動分配 (広告レシピ型) | 自動・公平・スケール可 | 不正PV対策必要、最低支払額の管理 | ★第一候補 |
| B. 投票連動分配 (人気投票型) | 質を反映 | ヒット作集中 | △ 補助 |
| C. 投げ銭 (Buy me a Coffee型) | 直接の応援、関係性深まる | UX 摩擦、税務複雑 | ★第二候補 |
| D. 月額有料作品 (note 有料記事型) | 高単価、作者主体 | 読者参入障壁 | △ Phase D |
| E. 一括払読切作品 (Kindle型) | 単価高、所有権感 | 流通量少 | △ Phase D |

→ **Phase 1: A + C 併用** (PV連動の自動分配 + 任意投げ銭)

## 3. PV連動分配 (Method A)

### 計算式

```
作者月収益 = (個人月間PV / 全体月間PV) × 還元プール
```

### 還元プール = 月収の何%を作者に還元するか

| 段階 | プール率 | 解説 |
|---|---|---|
| Year 1 (立上期) | 売上の 20% | 自社運営費を厚く確保 |
| Year 2 (拡大期) | 売上の 35% | 競合(YouTube 55%, note 90%)より低めだが粗利確保 |
| Year 3+ (成熟期) | 売上の 50% | 業界標準に近づける |

### 売上の定義

| 収益源 | プール組入 | 備考 |
|---|---|---|
| Reader Premium 月額 | ✅ 全額 | |
| Author Pro 月額 | ❌ | 自分のための課金なので非組入 |
| 広告収益 | ✅ 全額 | |
| 投げ銭 | ❌ 別系統 | 作者100% (手数料控除後) |
| 単発販売 | ❌ 別系統 | 作者70%, 運営30% |

### 計算例 (Year 1)

```
月の総売上: ¥500,000 (Premium 1000人 × ¥480 + 広告 ¥20,000)
還元プール: ¥500,000 × 20% = ¥100,000

総PV: 1,000,000
作者A の作品PV: 50,000 (5%)
作者A の月収益: ¥100,000 × 5% = ¥5,000
```

### 不正PV対策

- 同一IPからの連続アクセスは1PVカウント (1時間)
- 同一ユーザIDからの連投も同様
- VPN等の異常パターンは Cloudflare WAF で検知
- 自分の作品のPV不正計上を防止 (本人ログイン中のPVは集計除外)
- 異常な急上昇を検知し、機械的に保留 → 人手確認

### 最低支払額・支払サイクル

- 最低支払額: ¥3,000 (Stripe送金手数料との兼合)
- 支払サイクル: 月締め翌月末払い
- 未達の場合は翌月へ繰越
- 5年間未操作の場合は失効通知後に運営帰属

## 4. 投げ銭 (Method C)

### 仕様

- 1投げ銭あたり ¥100 / ¥300 / ¥1,000 / ¥3,000 / 任意額(最大 ¥50,000)
- メッセージ任意 (140文字)
- 公開設定: 公開 / 名前のみ / 完全匿名
- 作品ページに「投げ銭ランキング」「最新メッセージ」表示

### 手数料

| 区分 | 取り分 |
|---|---|
| Stripe 決済手数料 | 3.6% (例: ¥1,000 → ¥36) |
| プラットフォーム手数料 | 5% (例: ¥1,000 → ¥50) |
| **作者受取り** | 約 91.4% |

→ 業界平均(YouTube Super Chat: 30%控除、note: 10%)より作者有利。

### 実装

```sql
CREATE TABLE tips (
  id UUID PRIMARY KEY,
  work_id UUID REFERENCES works(id),
  author_id UUID REFERENCES auth.users(id),
  tipper_id UUID REFERENCES auth.users(id),
  amount INT, -- 円
  message TEXT,
  visibility TEXT, -- 'public'/'name'/'anon'
  stripe_payment_id TEXT,
  paid_at TIMESTAMPTZ DEFAULT NOW(),
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

## 5. 単発販売 (Method E, Phase D)

「電子書籍として完結作を ¥300 で販売」のようなモデル。  
Phase D で Stripe Checkout (one-time payment) を使い実装。

| 区分 | 取り分 |
|---|---|
| Stripe 決済手数料 | 3.6% |
| プラットフォーム手数料 | 30% |
| **作者受取り** | 約 66% |

(Kindle の 35-70% と Apple Books の 30% 控除を参考)

## 6. 作者向けダッシュボード機能

`AuthorPro` 加入者向け (無料作者は月次サマリのみ):

- 作品別 PV, ユニーク読者数, 平均完読率, 滞在時間
- 投票数推移グラフ
- 投げ銭一覧、累計収益
- PV連動分配の累計、推移
- 出金ボタン (¥3,000以上)
- 国別読者分布 (#17 多言語化と連動)

## 7. 運用・税務

| 項目 | 内容 |
|---|---|
| 報酬の源泉徴収 | 国内作者: 必要に応じて (10.21%, 通常は本人申告) |
| 作者の確定申告 | 年間合計¥200,000超で確定申告必要、運営は支払調書発行 |
| インボイス制度 | 適格請求書発行事業者の作者には消費税分上乗せ |
| 海外作者 | 国内源泉徴収後送金、各国の租税条約適用 (Phase D) |
| 規約改訂 | 利用規約「投稿コンテンツに関する権利」「報酬」項に明記 |

---

## 8. 法的留意点

- **電子マネー扱いではないか確認** → 出金可能なら資金移動業の規制適用される可能性。Stripe Connect 経由の銀行送金なら原則回避
- **作者の身元確認(KYC)** → ¥1,000,000/月以上の支払いは犯収法のKYC必要。Stripe Connect 標準フロー使用
- **未成年作者の対応** → 親権者同意必須、銀行口座は親権者名義
- **報酬の所有権** → 「報酬請求権はアカウントに帰属」と規約明記、譲渡禁止
