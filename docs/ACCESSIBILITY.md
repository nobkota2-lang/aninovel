> 状態: ガイドライン整備済 / 既存コード改修は段階的に実施

---

## 1. なぜアクセシビリティか

| 理由 | 効果 |
|---|---|
| **法的義務** | 障害者差別解消法(2024.4.1全事業者努力義務 → 公的機関は義務化) |
| **ユーザ層拡大** | 国内で視覚障害者31万人、聴覚障害者34万人、潜在的アクセシビリティ要求は人口の15%以上 |
| **SEO向上** | Googleはアクセシビリティを順位要因に組込 |
| **デバイス汎用性** | スクリーンリーダ、キーボード操作、音声入力、高齢者ユーザ |
| **訴訟回避** | アメリカではADA訴訟が年5,000件以上 |

## 7. 法的留意

- **障害者差別解消法 第8条**: 事業者は不当な差別的取扱いの禁止 + **合理的配慮の提供 (努力義務 → 義務化)**
- **JIS X 8341-3**: 国内アクセシビリティ規格、WCAG 2.0 と整合
- 公的機関相手のサービスは AA 準拠が事実上必須
- 訴訟リスク低減のため**「アクセシビリティ方針」公開**が推奨
