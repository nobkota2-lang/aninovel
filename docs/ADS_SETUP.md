# 広告(AdSense)セットアップ手順

> 状態: コード実装済 (`js/ads.js`) / **AdSense審査+ID埋込待ち**

---

## 1. AdSense 審査の前提条件 (重要)

**AdSenseは厳しい審査があります。以下が揃っていないと審査落ちします:**

- [ ] 独自ドメイン (`*.github.io` のサブドメインでは原則不可) ← #6 完了が必要
- [ ] プライバシーポリシー、利用規約の公開 ← #1 完了 ✅
- [ ] サイトに**オリジナルコンテンツが10ページ以上**
- [ ] サイトの利用者が一定数(目安: 月間1000PV以上)
- [ ] サイト内ナビゲーションが完備
- [ ] 18歳以上のGoogleアカウント
- [ ] 銀行口座(報酬振込先)

→ **#6 (独自ドメイン)、#7 (Analytics 設置)、コンテンツ投稿の蓄積、3ヶ月以上の運営実績**を経てからAdSense申請する流れになります。

---

## 2. AdSense アカウント作成と審査

1. https://www.google.com/adsense/start/ にアクセス
2. Googleアカウントでログイン → サイトURLと国を入力
3. AdSenseのコードをサイトの `<head>` に貼付 (一時的な確認用)
4. 「審査をリクエスト」を押下 → **数日〜2週間** で結果メール
5. 承認後、ダッシュボードから **広告ユニット作成**
6. 各広告枠の **`data-ad-slot` 番号** を取得

---

## 3. ID埋込

各HTMLの該当コメントを外す:

```html
<script>
  window.ANINOVEL_ADSENSE_PUBLISHER='ca-pub-1234567890123456';
  window.ANINOVEL_AD_SLOTS={
    inline:  '1234567890',  // 作品ビューワ内
    sidebar: '2345678901',  // サイドパネル(将来)
    footer:  '3456789012'   // 各ページフッター
  };
</script>
<script src="js/ads.js" defer></script>
```

---

## 4. 広告ポリシー(設計)

| 場所 | スロット名 | 表示条件 |
|---|---|---|
| トップページ作品一覧の下 | `footer` | 全ユーザ |
| 作品ビューワの最終ページ | `inline` | 無料ユーザのみ |
| サイドパネル下部 | `sidebar` | 無料ユーザのみ |

**作品本文中央への割込みは行わない**。読書体験を損なうため。

---

## 5. 自動非表示の条件

`js/ads.js` は以下のいずれかに該当するユーザに広告を表示しません:

1. **課金ユーザ** (`localStorage.aninovel_user.subscription === 'premium'` または `'author_pro'`)
2. **解析・Cookie に同意していないユーザ** (GDPR配慮)

→ #10 (Stripe決済) で `subscription` フィールドを設定すれば自動的に広告非表示になります。

---

## 6. 広告ブロッカー検知

10秒後に広告枠の表示状態をチェックし、ブロックされている場合は右下に小さな啓発メッセージを表示します。
**敵対的でなく、解除を強制しません**。ユーザの選択を尊重しつつ、広告非表示プランへの誘導を行います。

## 7. 収益試算 (目安)

| MAU | 平均PV/ユーザ | 月間PV | RPM (¥) | 月収 (目安) |
|---|---|---|---|---|
| 1,000 | 5 | 5,000 | 100 | ¥500 |
| 10,000 | 5 | 50,000 | 100 | ¥5,000 |
| 100,000 | 5 | 500,000 | 100 | ¥50,000 |
| 1,000,000 | 5 | 5,000,000 | 100 | ¥500,000 |

※ AdSenseのRPM(1000PVあたり収益)は日本ニッチコンテンツで¥80-200程度。
**広告だけで黒字化は MAU 10万人以上から**。それまでは課金プラン(#10)が主収益となる想定。

## 8. 代替広告ネットワーク

AdSense審査落ち / 補完目的で:

| 代替 | 特徴 |
|---|---|
| **Microsoft Advertising (旧Bing Ads)** | AdSenseより緩い審査、RPMほぼ同等 |
| **A8.net** | アフィリエイト、書籍広告と相性◎ |
| **もしもアフィリエイト** | 国内ASP、楽天/Amazonで書籍広告 |
| **A-port** | ジャンル特化、小説/コミック広告あり |
| **note記事広告** | コンテンツ内ネイティブ広告 |
